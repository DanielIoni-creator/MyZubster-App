# 🎨 MyZubster App - UI/UX Design

## 📱 Design System

### Colori
- **Primary**: #8b5cf6 (Viola)
- **Secondary**: #ec4899 (Rosa)
- **Success**: #4caf50 (Verde)
- **Background**: #0f0c29 (Scuro)

### Tipografia
- **Font**: Segoe UI
- **H1**: 32px Bold
- **H2**: 24px SemiBold
- **Body**: 16px Regular

### Componenti

#### Tab Bar
- Home 🏠
- Wallet 👛
- Garden 🌱
- Scan 📡
- Profile 👤

#### Card
- Background: rgba(255,255,255,0.05)
- Border: 1px solid rgba(255,255,255,0.08)
- Border-radius: 12px

#### Bottoni
- Primary: #8b5cf6
- Secondary: #ec4899
- Outline: rgba(255,255,255,0.1)

### Profile

## 🎯 User Flow

1. **Onboarding** → Login/Registrazione
2. **Dashboard** → Visualizzazione principale
3. **Wallet** → Pagamenti e transazioni
4. **Garden** → Gestione piante/animali
5. **Scan** → NFC/QR scanning
6. **Profile** → Impostazioni utente
